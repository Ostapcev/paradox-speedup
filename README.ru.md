# Ускорение игр Paradox — плагины

[English version](README.md)

Исходный код DLL-плагинов, которые ускоряют **Europa Universalis IV 1.37.5 (Steam и GOG, Windows x64)**, включая крупные моды вроде Anbennar, и **Hearts of Iron IV 1.19.5 (Steam, Windows x64)**. Позже здесь появятся плагины для других игр Paradox.

Готовые сборки удобнее ставить [установщиком](https://github.com/Ostapcev/paradox-speedup-launcher) (на русском и английском). Он сам находит игру, объясняет каждый плагин и настраивает его.

## Как это работает

Плагины — это обычные DLL в папке `plugins` рядом с `eu4.exe`. Их загружает `VERSION.dll` — загрузчик из EU4 Unicode Patch. Сам `eu4.exe` на диске не меняется: каждый плагин при запуске меняет код игры только в памяти.

Перед любым изменением плагин проверяет, та ли это версия игры:
- сборку `eu4.exe` (Steam или GOG 1.37.5, по заголовку PE);
- байты в каждом месте, которое он меняет.

Если что-то не совпало, плагин пишет в свой журнал `REFUSED` и ничего не трогает. У каждого плагина есть ini с режимом `off`/`disabled`.

Многие плагины умеют работать в теневом режиме (`shadow`): считают по-своему, сравнивают с результатом игры и пишут в журнал число расхождений. Так проверялась точность.

## Плагины EU4

| Папка | Что делает | Меняет ход игры? |
|---|---|---|
| `eu4_render_patch` | Реже рисует кадры на быстрой скорости (самое большое ускорение) | нет |
| `eu4_alloc_patch` | Быстрая работа с памятью | **да**: другой порядок адресов |
| `eu4_country_patch` | Расчёты по странам заранее, в несколько потоков; защита от вылета `relguard` | нет; 4 редких расчёта можно выключить |
| `eu4_ai_serial` | Кэши в расчётах ИИ | нет |
| `eu4_knowledge_patch` | Параллельный расчёт знания карты | нет |
| `eu4_modifier_patch` | Быстрый поиск и слияние модификаторов | нет |
| `eu4_gov_patch` | Запоминает свойства реформ правительства | нет |
| `eu4_pops_patch` | Убирает лишнее ожидание онлайн-сервисов Paradox | нет |
| `eu4_load_patch` | Быстрая загрузка игры и сохранений | нет |
| `eu4_loc_patch` | Быстрая загрузка локализации | нет |
| `eu4_menu_patch` | «Выйти в меню» без перезапуска | нет |
| `eu4_save_patch` | Быстрые сохранения | нет |

Экспериментальные и служебные папки (в установщик не входят):

| Папка | Назначение |
|---|---|
| `eu4_speed_patch` | Расписание поиска целей армейским ИИ |
| `eu4_trigger_patch` | Параллельные триггеры, только диагностика |
| `eu4_det_patch` | Фиксированный seed для воспроизводимых сравнений |
| `eu4_sampler` | Профайлер: стеки потоков игры |
| `eu4_bench` | Замер скорости по журналу `-gamestatetimer` |
| `eu4_port` | Перевод адресов Steam → GOG (см. ниже) |

## Плагины HoI4

Для HoI4 1.19.5.0 и 1.19.4.2 (Steam). Эти сборки различаются только строками версии и одной маленькой функцией разбора текста, которую плагины не трогают. `hoi4_common/hoi4_build.hpp` узнаёт обе сборки по PE-заголовку `hoi4.exe`; с любой другой плагины пишут `REFUSED` и ничего не меняют. На позднем сохранении (1941 год) игровой день идёт примерно 800–860 мс вместо 1020–1190 мс без плагинов.

| Папка | Что делает | Меняет ход игры? |
|---|---|---|
| `hoi4_loader` | Свой загрузчик плагинов `VERSION.dll` | нет |
| `hoi4_render_patch` | На быстрой игре реже обновляет кадры, графику провинций, модельки юнитов и 3D-сцену | нет (при `supply_interval=1`, как ставит установщик) |
| `hoi4_supply_patch` | Не пересчитывает пути снабжения страны, если её входные данные не изменились; результат побайтно как у игры | нет |
| `hoi4_tick_patch` | 23 мелких параллельных цикла часового тика выполняет в вызывающем потоке — штатным путём игры для одного задания | нет |
| `hoi4_load_patch` | Быстрее запуск и загрузка сохранений: реестр триггеров, индекс файлов, поиск стран по тегу | нет |
| `hoi4_alloc_patch` | Быстрое выделение памяти (порт `eu4_alloc_patch`) | **да**: другой порядок адресов |

Не входят в установщик: `hoi4_bench_helper` (включает наблюдателя для бенчмарка), `hoi4_sampler` (профайлер), `hoi4_bench` (замер скорости по журналу `-gamestatetimer`).

## Сборка

Нужен [Zig 0.13.0](https://ziglang.org/download/#release-0.13.0) (он же компилятор C++).

1. Распакуйте Zig в `.tools/zig-windows-x86_64-0.13.0/` в корне репозитория.
2. Положите копию игры в папку `Europa Universalis IV/` рядом с ним или поправьте путь `PLUGINS` в скриптах.
3. Соберите плагин:
   ```
   python eu4_country_patch/tools/build.py
   ```
   Скрипт собирает `build/<плагин>.dll` и копирует её в `Europa Universalis IV/plugins/`.

Плагины HoI4 собираются так же (`python hoi4_render_patch/tools/build.py`, с `--install` — копия в `Hearts of Iron IV/plugins/` рядом с репозиторием); загрузчик — `python hoi4_loader/tools/build.py`.

Для инструментов анализа (`eu4_sampler/tools`, `eu4_knowledge_patch/tools`, `eu4_port/tools`) нужен Python-пакет `capstone`: `pip install capstone`.

## Адреса в коде

Хуки привязаны к точным адресам (RVA) в `eu4.exe` 1.37.5 из Steam (SHA-256 `9ad3efe1af169f40ee577f9dae5debbc87af6fb8b5450fb345ebf110dc4d771a`). В комментариях функции игры указаны по адресам вида `140a5e130` (база образа `0x140000000`). В GOG-сборке той же версии (SHA-256 `5f4145ce5ff9a4140cc4d14440920382b698dd91e1cdae1d1dc053357d9388ee`) тот же код лежит по другим адресам. `eu4_port` сопоставляет функции двух сборок, а `eu4_port/include/eu4_build.hpp` во время работы переводит каждый Steam-адрес плагина, сверяя с байтами GOG, проверенными заранее (`eu4_gog_table.inc`). С другой версией игры плагины не включатся, пока адреса не обновлены.
