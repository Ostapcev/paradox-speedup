# EU4 Bench

Нужен, чтобы ответить на два вопроса:

1. **Насколько быстрее стала игра целиком.** Ответ даёт `bench.py`: сколько миллисекунд реального времени уходит на игровой день.
2. **Куда уходит время.** Ответ даёт профиль со стеками: `eu4_sampler` и `analyze_stacks.py`.

## Откуда берутся цифры

Если запустить игру с параметром `-gamestatetimer`, она сама пишет файл `Документы/Paradox Interactive/Europa Universalis IV/logs/gametimer_*.tsv`. Это делает функция `140daa4e0` (`gamestatetimer.cpp`), а строки добавляются из дневного тика `140758430`.

Строка `Day` — это реальное время между двумя соседними игровыми днями, включая отрисовку. Такая метрика честнее, чем счётчики отдельных участков внутри плагинов.

## Чтобы прогоны можно было сравнивать

- Все прогоны начинаются с **одного эталонного сохранения**. `bench.py run` копирует его в `save games/eu4_bench_run.eu4` и направляет на эту копию `continue_game.json`. Игра запускается с `-continuelastsave`. Ваш собственный `continue_game.json` возвращает команда `report`.
- Лучше брать сохранение **в режиме наблюдателя**: тогда нет действий игрока.
- Во время прогона ставьте **скорость 5**, не ставьте игру на паузу и не открывайте лишние окна. Дни длиннее 15 с считаются паузой и отбрасываются, их даты выводятся в отчёте.
- Первые 30 дней после загрузки не учитываются: это разгон, когда заполняются кэши.
- ИИ со временем расходится, и мир в разных прогонах становится разным. Поэтому сравнивается **один и тот же промежуток дат**, и надёжнее всего первые 1–2 игровых года.
- Для замеров скорости режимы `shadow` и `profile` не годятся: они сами добавляют нагрузку.

## Порядок работы

Сначала прогон без ускорителей:

```bash
python eu4_bench/bench.py run vanilla --save "%USERPROFILE%/Documents/Paradox Interactive/Europa Universalis IV/save games/ВАШ_СЕЙВ.eu4"
```

В игре снимите паузу, поставьте скорость 5, дождитесь, пока пройдёт 1–2 игровых года, и выйдите из игры. Потом сохраните результат:

```bash
python eu4_bench/bench.py report
```

Затем прогон со всеми плагинами. Путь к сохранению указывать уже не нужно, он запомнился:

```bash
python eu4_bench/bench.py run all
```

```bash
python eu4_bench/bench.py report
```

Сравнение двух прогонов:

```bash
python eu4_bench/bench.py compare vanilla all
```

В выводе `compare`:

- разница времени дня с 95-процентным интервалом. Интервал считается блочным бутстрэпом по 30 дней, потому что соседние дни связаны между собой;
- во сколько раз изменилась скорость;
- предупреждение, если разница не выходит за пределы шума.

Пресеты можно посмотреть командой `bench.py presets`. Режим отдельного плагина меняется через `--set`, например `--set knowledge=optimized`. Если не нужно трогать ini вообще, используйте пресет `current`.

Прочие команды:

- `bench.py modes` — показать текущие режимы плагинов;
- `bench.py restore` — вернуть ini в состояние до первого прогона;
- `bench.py parse ФАЙЛ.tsv` — разобрать любой лог `gametimer`.

## Профиль со стеками

Пока игра идёт на скорости 5:

```bash
python eu4_bench/bench.py profile --seconds 60
```

То же самое можно сделать файлом `Europa Universalis IV/profiler/profile_eu4.cmd`.

Результат попадает в `results/<метка>_profile_*/`:

- `subsystems.csv` — разбивка по шагам дневного, месячного и годового тиков, по отрисовке и по POPS. Каждый сэмпл попадает ровно в одну строку: он относится к самому глубокому шагу в своём стеке.
- `crosscut.csv` — сквозные группы: триггеры, модификаторы, `RefreshKnowledge`, армейский ИИ, `malloc`, сохранение. Группы пересекаются, их сумма может быть больше 100%.
- `inclusive_functions.csv` — время самой функции и полное время вместе с вызовами.
- `folded.txt` — стеки для флеймграфа. Файл можно перетащить на https://www.speedscope.app.

Чтобы увидеть, как изменились доли подсистем относительно другого профиля, добавьте `--diff ПАПКА_ДРУГОГО_ПРОФИЛЯ`.

## Проверка инструментов

```bash
python eu4_bench/tests/test_bench.py
```

```bash
python eu4_sampler/tools/build.py
```

```bash
python eu4_sampler/tools/integration_test.py
```

`test_bench.py` проверяет правку ini на копиях, разбор tsv с паузой и автосохранением и сравнение прогонов с заранее известной разницей в −10%. `integration_test.py` проверяет, что стеки снимаются от корня до листа и что лист в них не повторяется.
