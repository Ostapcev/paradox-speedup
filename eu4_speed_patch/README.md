# EU4 Speed Patch

Экспериментальный DLL-плагин для **EU4 1.37.5.0 Inca, Windows x64**.

Первая версия уменьшает число полных поисков целей армейским ИИ. В оригинале армии стран, связанных с игроком, повторяют тяжёлый поиск каждый день. Режим `balanced` возвращает им штатное расписание: одна армия ищет цель раз в три дня, разные армии распределены по дням.

Это **не ускорение без изменения поведения**: такие армии могут на один–два дня позже среагировать на новую цель. Формулы оценки провинций, команды ИИ, экономика, RNG и игровые сохранения не изменяются. Многопоточность игры также не изменяется.

## Режимы

В `plugins/eu4_speed_patch.ini`:

```ini
[speed]
mode=balanced
```

- `balanced` — ускорение, трёхдневное расписание поиска;
- `profile` — оригинальное поведение игры, только счётчики и время поиска;
- `disabled` — хуки не устанавливаются, память игры не изменяется.

Изменения применяются при следующем запуске игры.

## Установка

Нужен загрузчик `VERSION.dll`, который загружает DLL из `plugins` — например, загрузчик из Matanki EU4dll или EU4 Unicode Patch. Этот пакет загрузчик не содержит.

1. Полностью закройте игру и сделайте резервную копию сохранения.
2. Скопируйте содержимое `plugins` из архива в папку `plugins` рядом с `eu4.exe`.
3. Для первого теста используйте обычную одиночную игру, не ironman.
4. Запустите игру и проверьте `plugins/eu4_speed_patch.log`.

Удаление: закройте игру и удалите `plugins/eu4_speed_patch.dll`. Файл `eu4.exe` на диске не изменяется.

## Проверка эффекта

1. Загрузите одно и то же сохранение с `mode=profile`, не ускоряйте время выше обычного и подождите несколько игровых месяцев.
2. Повторите тест с `mode=balanced`.
3. Сравните строки `stats`: `searches`, `search_total_ms` и `average_us`.

`searches` — фактическое число полных поисков; `search_total_ms` — суммарное время внутри оригинального поиска; `average_us` — средняя длительность одного вызова. Это метрики только выбранного участка, а не FPS и не время всего игрового дня. Суммарное время корректно сравнивать на одинаковом игровом интервале.

## Совместимость и ограничения

- Перед установкой проверяются PE-разметка, прологи функций, оба `call` и продолжения инструкций. При несовпадении DLL пишет `REFUSED` и не меняет память игры.
- Контрольный SHA-256 эталонного `eu4.exe`: `9ad3efe1af169f40ee577f9dae5debbc87af6fb8b5450fb345ebf110dc4d771a`. Другой хеш сам по себе не запрещает загрузку, если все сигнатуры совпали.
- Другие патчи тех же инструкций обнаруживаются как конфликт.
- Плагин меняет решения ИИ по времени, поэтому для мультиплеера лучше использовать одинаковую конфигурацию у всех, но первичное тестирование рекомендуется только в одиночной игре.
- Совместимость с достижениями и ironman не гарантируется.
- Выгрузка DLL на лету не поддерживается; отключение и удаление выполняются после выхода из игры.

## Статусы и экспорт

`EU4SpeedPatchStatus`: `1` — `balanced`, `2` — `profile`, `3` — `disabled`, `0` — инициализация, отрицательное значение — отказ. `EU4SpeedPatchSearchCount` возвращает число измеренных поисков.

## Сборка

Исходники: C++17, Windows x64. В этой рабочей папке сборка проверяется локальным Zig 0.13.0:

```sh
python eu4_speed_patch/tools/build.py
eu4_speed_patch/build/hook_tests.exe
eu4_speed_patch/build/speed_patch_check.exe "Europa Universalis IV/eu4.exe"
```

Готовый пакет создаётся в `eu4_speed_patch/dist`.
